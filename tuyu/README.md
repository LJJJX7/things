# 图舆 · 照片地图合成器

单文件网页工具：把一张实景照片，叠成一张带真实地理信息的旅行杂志风格画面。

## 运行

双击 `图舆-照片地图合成器.html`，用电脑 Chrome / Edge 打开即可。无需安装、无需后端、无需 API Key。

## 能做什么

- 照片调色：5 个预设 + 8 项手动参数（亮度/对比度/饱和度/色温/色调/阴影/高光/颗粒）+ 暗角
- 真实地图：按地名拉取 OpenStreetMap 矢量数据，渲染道路、水系、地名、地标
- 编辑风图层：透明底、柔边遮罩、纸感颗粒、城市名水印、指北针、拍摄点红点
- 日夜自适应：按整张照片亮度自动切换深色墨线 / 浅色线条
- 四个图层参数：融合强度、边缘渐隐、细节密度、大小
- 画幅与原图一致，导出 PNG / JPG，最长边上限 6000px

## 操作

1. 上传照片
2. 输入地名（如 昆山 / Paris / 埃菲尔铁塔）→ 生成
3. 拖动 / 滚轮调整地图位置与大小
4. 导出

## 数据与许可

- 地图数据 © OpenStreetMap contributors，ODbL 许可
- 矢量瓦片：OpenFreeMap（https://openfreemap.org）
- 地名检索：Photon / Nominatim
- 渲染：自研 Canvas 实现，未使用第三方地图 JS 库

## 已知限制

- 需要联网获取瓦片；断网时只能使用「上传本地透明底地图 PNG」
- 地标名称来自 OSM，城市越大越完整；小地方可能没有地标
- 背景过于细碎的照片（例如满幅树冠）会让地图接近不可见，这是对比度的限制，不是 bug

## 隐私

图片全程在浏览器本地处理，不上传任何服务器。
